# EcoSort quality contract

The supplied master prompt is the product specification. Ship the whole request → assignment → collection → destination record journey, not a complaint-only app.

- Strict TypeScript; no ignored errors or skipped tests. Build, lint, unit/component tests and browser workflow must execute.
- Demo and connected mode share types, validation and UI; production authorization is enforced by PostgreSQL RLS and atomic RPCs, not role selectors.
- Synthetic data only in demo; no invented live statistics, AI, partnerships or treatment outcomes.
- Private household locations and photographs are accessible only to authorized users.
- Keyboard-accessible controls, visible focus, responsive navigation, real error/empty/loading states.
- Maps use OSM when online and remain usable as a coordinate view offline; the core classroom workflow requires no external service.
- Connected-mode verification requires an actual Supabase project and credentials; untested integration is documented honestly.

Design contract: warm off-white canvas, forest-green navigation, sage accents, system typography, 8px spacing, restrained 16px card corners. Desktop uses a sidebar; mobile uses a compact header and bottom navigation. Operational content precedes decoration.
